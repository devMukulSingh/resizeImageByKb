# ResizeImageByKB.biz — Online Image Compressor, Resizer & Editing Tools
https://resizeimagebykb.biz/

ResizeImageByKB.biz is a fast, secure, browser-based image optimization toolkit that helps users **compress, resize, crop, rotate, mirror, pixelate, and convert images** — all without uploading files to any server. Everything is processed **client-side**, ensuring privacy and instant results.

## 🚀 Features

### 🔹 Image Compression (Resize by KB)
- Resize images to **20KB, 50KB, 100KB, or any custom KB**.
- Compress **JPG, PNG, WebP** with up to **90% reduction**.
- Convert **MB → KB** automatically.
- Before/after preview.
- 100% browser-based — images never leave your device.

### 🔹 Image Resizer
- Resize by **pixel**, **percentage**, or **preset sizes**.
- Social media presets (Instagram, Facebook, YouTube).
- Real-time preview.
- Batch resizing.
- High-quality output.

### 🔹 Image Cropper
- Freeform cropping.
- Aspect ratios: **1:1, 4:3, 16:9**, etc.
- Drag, zoom, rotate.
- Grid overlay for accuracy.

### 🔹 Rotate Tool
- Rotate **90° / 180° / 270°**.
- Custom rotation angle.
- Flip horizontally or vertically.
- EXIF orientation fix.

### 🔹 Mirror / Flip Tool
- Horizontal & vertical flip.
- Combine with rotation.
- No quality loss.

### 🔹 Grayscale Converter
- Convert any image to **black & white**.
- Sharp grayscale conversion.
- Batch grayscale support.

### 🔹 Pixelate Tool
- Adjustable pixel intensity.
- Pixelate full or partial image.
- Ideal for blurring faces & sensitive data.
- Retro pixel-art effects.

### 🔹 Image Format Converter
- Convert **JPG ↔ PNG ↔ WebP ↔ GIF ↔ BMP**.
- Batch format conversion.
- Optimized output quality.
